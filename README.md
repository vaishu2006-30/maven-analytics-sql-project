# Restaurant Orders SQL Analysis

## Project Overview
This project analyzes restaurant menu items and order details using SQL. It is based on the Restaurant Orders dataset from Maven Analytics.

## Objectives
- Analyze menu items and their prices.
- Identify the most and least ordered dishes.
- Find order trends and order counts.
- Calculate the highest-spending orders.
- Explore relationships between menu items and order details.

## SQL Concepts Used
- SELECT and WHERE
- COUNT, SUM, AVG, MIN and MAX
- GROUP BY and ORDER BY
- JOIN
- Subqueries
- HAVING and LIMIT

## Files Included
- `restaurant_order_analysis.sql` – SQL queries used for the analysis.

## Tools Used
- MySQL
- SQL
- Maven Analytics Restaurant Orders dataset

## Learning Outcome
Practiced SQL queries, table joins, aggregate functions, and subqueries to analyze restaurant order data.
